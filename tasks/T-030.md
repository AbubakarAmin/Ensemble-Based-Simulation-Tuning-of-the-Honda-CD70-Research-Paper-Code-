Builds the ensemble of plausible engines for reading B (this is the main case).
HOW TO RUN THIS LONG JOB (follow exactly):
0. Load the skill `run-long-job` (skill tool, name run-long-job) if you have not in this session.
1. Start (or resume) it: `python scripts/jobs.py ensure cal_B -- python scripts/run_many.py cal_B`
2. Wait: `python scripts/jobs.py wait cal_B --timeout 100`. Repeat this wait up to 200 times. Between waits do NOTHING else (no other heavy jobs).
3. If it prints RUNNING after 200 waits: run `python scripts/session_finish.py "waiting for cal_B"` and STOP. The next session continues at this same task.
4. If it prints QUEUED: another job is running. Run `python scripts/jobs.py status`, wait for that one first.
5. If it prints FAILED or DEAD: run `python scripts/jobs.py log cal_B`, then run step 1 again (resuming is safe, finished parts are skipped). Same error twice in a row: `python scripts/task.py block T-030 "<error text>"`.
6. When it prints OK, run `python scripts/task.py done T-030`.

The gate demands at least 100 accepted engines. If the job is OK but fewer than 100 were accepted, block the task with the printed numbers (do not change any config).
