This is a rehearsal at tiny scale to prove the code works on this computer. Results are thrown away later.
HOW TO RUN THIS LONG JOB (follow exactly):
0. Load the skill `run-long-job` (skill tool, name run-long-job) if you have not in this session.
1. Start (or resume) it: `python scripts/jobs.py ensure smoke_cal -- python scripts/run_many.py cal_B --scale smoke`
2. Wait: `python scripts/jobs.py wait smoke_cal --timeout 100`. Repeat this wait up to 200 times. Between waits do NOTHING else (no other heavy jobs).
3. If it prints RUNNING after 200 waits: run `python scripts/session_finish.py "waiting for smoke_cal"` and STOP. The next session continues at this same task.
4. If it prints QUEUED: another job is running. Run `python scripts/jobs.py status`, wait for that one first.
5. If it prints FAILED or DEAD: run `python scripts/jobs.py log smoke_cal`, then run step 1 again (resuming is safe, finished parts are skipped). Same error twice in a row: `python scripts/task.py block T-020 "<error text>"`.
6. When it prints OK, run `python scripts/task.py done T-020`.

Then do the same for the other three small groups, one after the other (each is quick):
`python scripts/jobs.py ensure smoke_base -- python scripts/run_many.py base_B --scale smoke`
`python scripts/jobs.py ensure smoke_sens -- python scripts/run_many.py sens_B --scale smoke`
Wait for each to print OK. Only then run the done command.
