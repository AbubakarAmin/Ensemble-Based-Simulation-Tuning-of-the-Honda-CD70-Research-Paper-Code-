Question: how well does the calibrated model match real fuel figures, using the same definitions as those figures?
This task changes no calibration, optimiser or locked result. It only adds a comparison.
HOW TO RUN THIS LONG JOB (follow exactly):
0. Load the skill `run-long-job` if you have not in this session.
1. Start (or resume) it: `python scripts/jobs.py ensure fuelval -- python scripts/fuel_validation.py`
2. Wait: `python scripts/jobs.py wait fuelval --timeout 100`. Repeat this wait up to 200 times. Between waits do NOTHING else (no other heavy jobs).
3. If it prints RUNNING after 200 waits: run `python scripts/session_finish.py "waiting for fuelval"` and STOP.
4. If it prints QUEUED: run `python scripts/jobs.py status` and wait for the other job first.
5. If it prints FAILED or DEAD: run `python scripts/jobs.py log fuelval`, then run step 1 again. Same error twice in a row: `python scripts/task.py block T-035 "<error text>"`.
6. When it prints OK, read reports/fuel_validation.md (the SUMMARY line and the table). Copy numbers from it only.
7. If `data/raw/fuel_log.csv` does not exist, that is fine: the report says NOT AVAILABLE for your own log. Tell the user once (in the session-end note) that a fill-up log would be the strongest check, and that the template is data/raw/fuel_log_template.csv.
8. Do NOT change config/validation.yaml to make a figure agree. Results that disagree are results.
9. Run `python scripts/task.py done T-035`.
