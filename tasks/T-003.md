1. If there is no `.git` folder, run: `git init`.
2. Run: `git add -A`.
3. Commit with the identity passed on the command line. Do NOT run `git config` (it is not allowed in this project):
   `git -c user.name=research-agent -c user.email=agent@localhost commit -m "initial research pack"`
   If git says there is nothing to commit and a commit already exists, that is fine.
4. Run `python scripts/task.py done T-003`.
(Windows note: all commands in these tasks are plain `python ...` commands and work in PowerShell, cmd or bash. If `python` is not found try `py`.)
