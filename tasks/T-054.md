Picks three designs per hardware class from the robust Pareto front: econ (least fuel, torque not lower), power (most torque, fuel not higher), knee (best compromise).
HOW TO RUN THIS LONG JOB (follow exactly):
0. Load the skill `run-long-job` (skill tool, name run-long-job) if you have not in this session.
1. Start (or resume) it: `python scripts/jobs.py ensure pick_B -- python scripts/run_many.py pick_B`
2. Wait: `python scripts/jobs.py wait pick_B --timeout 100`. Repeat this wait up to 200 times. Between waits do NOTHING else (no other heavy jobs).
3. If it prints RUNNING after 200 waits: run `python scripts/session_finish.py "waiting for pick_B"` and STOP. The next session continues at this same task.
4. If it prints QUEUED: another job is running. Run `python scripts/jobs.py status`, wait for that one first.
5. If it prints FAILED or DEAD: run `python scripts/jobs.py log pick_B`, then run step 1 again (resuming is safe, finished parts are skipped). Same error twice in a row: `python scripts/task.py block T-054 "<error text>"`.
6. When it prints OK, run `python scripts/task.py done T-054`.

Then, if T-053 is done, also run group pick_A (job name pick_A).
